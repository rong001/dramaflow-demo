# 剧链 DramaFlow · AI 短剧自动化平台（体验版）

在线体验：https://rong001.github.io/dramaflow-demo/

- 纯前端静态站点，**所有生成内容均为模拟数据**，不调用任何真实模型；投放看板为演示数据。
- 演示账号：页面上点「使用演示账号一键登录」，或 `demo@dramaflow.app` / `demo2026`。
- 流程：登录 → 新建项目 → 选模板/自配风格 → 一句话创意 → 选题报告 → 剧本与分集大纲 → 角色与服装 → 分镜表 → 画面生成 → 配音配乐 → 剪辑时间线 → 字幕包装 → 合规审核（AI 生成标识，关口不过不能导出）→ 成片预览与导出 → 投放与数据看板。
- 状态保存在浏览器 localStorage。画面为抽象几何占位帧，不描绘任何真人；示例剧本人物均为虚构。
